## 23. PlatformIO PATH и результаты сборки ESP32

**Промпт пользователя:**

> как мне сделать чтобы тебе тоже был доступен PIO? я запускаю терминал через ctrl+shift+p и ввожу команду PlatformIO: New Terminal. если просто открыть терминал то в нем PIO недоступен.
>
> запустил команды - вот вывод
>
> ... `pio run -e esp32` ... `SUCCESS`
>
> ... `pio run -e esp32 -t uploadfs` ... `Failed to connect to ESP32-S3: No serial data received`

**Результат:**

- Объяснено, что `pio` доступен только в терминале PlatformIO из-за отдельного окружения PATH.
- Предложено найти путь через `where pio`.
- Объяснено, что `pio run -e esp32` успешно подтверждает сборку прошивки.
- Объяснено, что ошибка `uploadfs` связана с отсутствием подключения к плате или неверным COM-портом, а не с кодом.
